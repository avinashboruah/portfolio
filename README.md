# Avinash Boruah — Portfolio

A personal developer portfolio built with React and Tailwind CSS, featuring an interactive 3D background and dynamic GitHub project integration.

[![React](https://img.shields.io/badge/React-19-blue?logo=react&style=flat-square)](https://react.dev/)

## 🛠️ Tech Stack

- **Frontend**: React 19, Tailwind CSS v4, React Router
- **3D Graphics**: Three.js, Vanta.js
- **Build Tool**: Vite 7
- **Icons**: React Icons
