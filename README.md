# Avinash Boruah — Portfolio

A personal developer portfolio built with React and Tailwind CSS, featuring an interactive 3D background and dynamic GitHub project integration.

[![React](https://img.shields.io/badge/React-19-blue?logo=react&style=flat-square)](https://react.dev/)
[![Vite](https://img.shields.io/badge/Vite-7-646CFF?logo=vite&style=flat-square)](https://vitejs.dev/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-v4-38B2AC?logo=tailwindcss&style=flat-square)](https://tailwindcss.com/)

---

## ✨ Features

- **Interactive 3D Background**: Dynamic net mesh built with Vanta.js and Three.js.
- **Dual Resume Switcher**: Quick toggle between Full-Stack and AI Engineer resumes.
- **Dynamic Projects**: Auto-fetched from GitHub API with caching and smooth sideways scrolling.
- **Certificates**: Highlighted achievements with skeleton loading animations.
- **Theme Support**: Seamless dark and light mode toggle.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Tailwind CSS v4, React Router
- **3D Graphics**: Three.js, Vanta.js
- **Build Tool**: Vite 7
- **Icons**: React Icons

---

## 🚀 Quick Start

```bash
# Clone the repo
git clone https://github.com/avinashboruah/portfolio.git

# Install dependencies
npm install

# Run dev server
npm run dev
```
